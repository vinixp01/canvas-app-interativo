# Canvas App Interativo 🎨

App web interativo inspirado em ferramentas de design como Figma, permitindo criar, editar e manipular elementos visuais em um canvas.

## 🚀 Como Começar

### 1. Clone o repositório
```bash
git clone https://github.com/vinixp01/canvas-app-interativo.git
cd canvas-app-interativo
```

### 2. Instale as dependências
```bash
npm install
```

### 3. Inicie o app
```bash
npm start
```

O app será aberto automaticamente em `http://localhost:3000`

## ✨ Funcionalidades

- ✅ **Seleção de elementos** - Selecione e mova elementos no canvas
- 🔵 **Desenho de círculos** - Clique no botão e adicione círculos
- ⬜ **Desenho de retângulos** - Clique no botão e adicione retângulos
- 🔤 **Adicionar texto** - Insira textos customizados
- 🎨 **Cores personalizadas** - Altere as cores dos elementos
- 🔄 **Rotação** - Rotacione elementos livremente
- 📊 **Painel de propriedades** - Ajuste posi­ção, tamanho, cor e rotação
- 🗑️ **Deletar elementos** - Remove elementos selecionados
- 📐 **Grid de referência** - Grid visual para auxiliar no posicionamento
- 🖱️ **Drag & Drop** - Mova elementos arrastando com o mouse

## 🎮 Como Usar

1. **Clique em um botão de ferramenta** (Círculo, Retângulo, Texto)
2. **Um novo elemento será criado** no centro da tela
3. **Arraste para mover** o elemento selecionado
4. **Use o painel de propriedades** à direita para ajustar:
   - Posição (X, Y)
   - Tamanho (Largura, Altura)
   - Cor
   - Rotação
5. **Clique em Deletar** para remover o elemento

## 🛠️ Tecnologias

- **React 18** - Framework JavaScript
- **HTML5 Canvas** - Rendering de gráficos
- **CSS3** - Estilização moderna
- **JavaScript ES6+** - Lógica da aplicação

## 📦 Build para Produção

```bash
npm run build
```

Isto cria uma versão otimizada da aplicação na pasta `build/`
